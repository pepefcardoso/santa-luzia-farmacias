# CHECKLIST — Transição e Configuração WhatsApp Business

## 1. Antes da migração

- [ ] Fazer backup manual do WhatsApp atual (Google Drive/iCloud)
- [ ] Avisar contatos frequentes que o número muda de app (opcional, mas evita estranhamento)
- [ ] Escolher horário de menor movimento pra migrar (ex: fim de tarde, loja mais vazia)
- [ ] Confirmar acesso ao número (SIM card ou eSIM no celular) para receber o SMS/ligação de verificação

## 2. Migração

- [ ] Instalar WhatsApp Business
- [ ] Escolher "usar número existente"
- [ ] Confirmar transferência de conta e histórico quando solicitado
- [ ] Validar via SMS/ligação
- [ ] Conferir se conversas e mídias antigas aparecem corretamente
- [ ] Testar envio/recebimento de mensagem teste

## 3. Perfil comercial

- [ ] Nome comercial (nome da farmácia)
- [ ] Categoria: Farmácia/Drogaria
- [ ] Foto de perfil (logo)
- [ ] Descrição curta (o que vocês vendem/diferenciais)
- [ ] Endereço de cada loja (se endereços diferentes, ver item 3.1)
- [ ] Horário de funcionamento
- [ ] E-mail de contato (opcional)
- [ ] Site (link do GitHub Pages)

### 3.1 Se as duas lojas tiverem WhatsApp separado

- [ ] Decidir se cada loja terá número próprio ou se centralizam num único número
- [ ] Se separado, repetir toda a configuração (catálogo, saudação, etiquetas) em cada conta

## 4. Catálogo de produtos

- [ ] Listar 15-20 produtos mais vendidos/buscados para cadastro inicial (não precisa cadastrar tudo de uma vez)
- [ ] Para cada item: foto, nome, preço (ou "sob consulta" se variar), descrição breve
- [ ] Criar categorias (ex: Medicamentos, Higiene, Beleza, Infantil, Promoções)
- [ ] Destacar itens diferenciais (teste de glicemia, aferição de pressão como "serviço" no catálogo)
- [ ] Adicionar link do catálogo na bio do Instagram/Facebook

## 5. Mensagem de saudação

- [ ] Ativar mensagem de saudação
- [ ] Definir texto (nome da farmácia + horário de atendimento + como pode ajudar)
- [ ] Definir público: todos ou só quem não conversa há X dias
- [ ] Definir horário de exibição (ex: sempre, ou fora do expediente)

**Exemplo de texto:**
> Olá! 👋 Bem-vindo à Farmácia [Nome]. Nosso horário é [HORÁRIO]. Como podemos te ajudar hoje?

## 6. Mensagem de ausência

- [ ] Ativar mensagem de ausência
- [ ] Definir horário de envio (fora do expediente)
- [ ] Texto informando horário de retorno

**Exemplo de texto:**
> No momento estamos fora do horário de atendimento. Funcionamos de [DIAS] das [HORÁRIO]. Assim que abrirmos, respondemos você!

## 7. Respostas rápidas (atalhos)

- [ ] `/horario` — horário de funcionamento das duas lojas
- [ ] `/entrega` — como funciona o delivery, taxa, prazo
- [ ] `/endereco` — endereço + link Google Maps de cada loja
- [ ] `/pagamento` — formas de pagamento aceitas
- [ ] `/promo` — promoções ativas no momento (atualizar semanalmente)
- [ ] `/farmaceutico` — info sobre atendimento farmacêutico presencial

## 8. Etiquetas

- [ ] Criar etiqueta "Novo cliente"
- [ ] Criar etiqueta "Aguardando pagamento"
- [ ] Criar etiqueta "Pedido em entrega"
- [ ] Criar etiqueta "Cliente recorrente"
- [ ] Criar etiqueta "Avaliação pendente" (pós-venda, pra lembrar de pedir avaliação Google)

## 9. Ferramentas extras

- [ ] Ativar estatísticas (mensagens enviadas/lidas/recebidas) para acompanhar volume
- [ ] Configurar link direto `wa.me/55SEUNUMERO?text=MENSAGEM` com texto pré-preenchido
- [ ] Adicionar esse link no site, Instagram, Facebook e Google Business
- [ ] Se equipe for usar o WhatsApp (mais de 1 pessoa), configurar dispositivos vinculados (até 4)

## 10. Pós-configuração

- [ ] Testar fluxo completo como se fosse cliente (mandar mensagem, ver saudação, testar atalho, ver catálogo)
- [ ] Treinar quem for atender sobre uso das etiquetas e respostas rápidas
- [ ] Definir tempo máximo de resposta como meta interna (ex: até 15 min em horário comercial)
